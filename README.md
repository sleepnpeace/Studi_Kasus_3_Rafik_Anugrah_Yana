# tugas_praktikum_3DDP

Penjelasan Kode

1. Untuk menginisiasi tuple batas_nilai(65, 100) dan list nilai_masuk, list lulus, dan list remedi. ketiga list dibuat kosong karena nilai akan dimasukkan satu per satu selama program berjalan.
![alt text](https://github.com/sleepnpeace/tugas_praktikum_3DDP/blob/main/Images/pic%201.png?raw=true)


2.Kode ini digunakan untuk memasukkan nilai secara berulang. Jika mengetik selesai, program berhenti. Nilai kemudian dicek apakah 0–100. Jika valid, nilai dimasukkan ke nilai_masuk. Jika nilai > 65 masuk ke lulus, sedangkan jika nilai < 65 masuk ke remedi. Jika nilai di luar 0–100, program menampilkan pesan kesalahan.
![alt text](https://github.com/sleepnpeace/tugas_praktikum_3DDP/blob/main/Images/pic%202.png?raw=true)

3.Kode ini digunakan untuk menghapus nilai yang salah input. Program menampilkan nilai yang ada print("\nNilai masuk:", nilai_masuk), lalu meminta pengguna memasukkan nilai yang ingin dihapus (ketik "tidak" jika tidak ada). Jika nilai ditemukan, nilai tersebut dihapus dari nilai_masuk, lulus, atau remedi. Jika tidak ditemukan, program menampilkan "Nilai tidak ditemukan."
![alt text](https://github.com/sleepnpeace/tugas_praktikum_3DDP/blob/main/Images/pic%203.png?raw=true)

4. Kode ini berfungsi untuk menampilkan output dari tuple batas nilai, dan output total list nilai masuk, list lulus, dan list remedi berdasarkan nilai yang sudah kita input dan hapus (jika ada yang dihapus)
